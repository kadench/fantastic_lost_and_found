Overview

The identity combines comic-book impact with a dark, editorial foundation. Saturated primary colors function as accents, not interchangeable text colors. A primary symbol is intentionally absent pending human-made artwork.

Identity system

LOST & FOUND

Display: Archivo Black. Body: DM Sans. Square primary mark: reserved artwork slot, 1:1 ratio, minimum 40 × 40 px in navigation and 256 × 256 px source specification. No generated illustration or emblem is supplied.

Color system

Saturated colors are deliberately separated from their dark, accessible text counterparts. Raw accent colors are not automatically approved as body-text foregrounds.

Buttons

Actions are identified by visible text and shape. Hover, active, disabled, loading, and keyboard focus have distinct presentations.

Accessibility

  • WCAG 2.2 AAA target for applicable text contrast, verified by foreground/background role.
  • Color is never the sole indication of an error, state, or action.
  • Native inputs, labeled controls, landmarks, semantic headings, and visible keyboard focus.
  • Minimum responsive target at 320 CSS px, including 400% zoom checks.
  • Reduced-motion media query suppresses optional animated effects.
  • Human review and assistive-technology testing remain required before claiming AAA conformance.
